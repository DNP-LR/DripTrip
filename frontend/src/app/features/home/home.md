**landing page structure** for _My Cameroon Guide_ with detailed components for

## 🌍 1. Header / Navbar

### Components:

- **Logo**: Top-left corner (small version of brand + wordmark)
- **Navigation Menu**:
  - Home
  - Discover (dropdown: Attractions, Cities, Regions)
  - Plan Trip (dropdown: Itineraries, Budgeting Tools)
  - Badges (Gamification section)
  - Partners (Hotels, Agencies)
  - About Us
- **Language Toggle**: 🇬🇧 / 🇫🇷 switch
- **Accessibility Menu**: Font size toggle, high contrast mode
- **Call-to-Action Button**: “Start Exploring” (styled in tropical blue)

### Components:
